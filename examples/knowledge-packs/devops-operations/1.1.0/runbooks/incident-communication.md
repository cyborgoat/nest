# Incident Communication Runbook

## Goal

Keep internal teams and customers aligned during active incidents.

## Update cadence

- Sev-1: every 30 minutes
- Sev-2: every 60 minutes
- Sev-3: on major status change

## Update format

1. Current impact
2. Scope and affected users
3. Mitigation progress
4. Next update time

This file is included in 1.1.0 to demonstrate versioned content additions.
