# Discovery Kickoff Playbook

## Inputs

- Problem statement
- Baseline metrics
- User segments

## Workshop agenda

1. Clarify problem and constraints
2. Map user journeys
3. List assumptions and risks
4. Define experiment plan

## Outputs

- Prioritized opportunity list
- Experiment backlog
- Owners and milestones
