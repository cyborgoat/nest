# Release Readiness Playbook

## Checklist

- [ ] Scope freeze date confirmed
- [ ] QA signoff complete
- [ ] Monitoring/alerts configured
- [ ] Rollback plan tested
- [ ] Support/docs briefed

## Go/No-go criteria

1. No Sev-1 defects open.
2. Core journeys pass end-to-end tests.
3. On-call handoff complete.
