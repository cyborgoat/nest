# Nest 工作原理

Nest 使用普通文件夹和 Markdown 文件保存知识。已安装的知识包包含
`pack.json`，但从文件夹导入前无需手动创建它；Nest 可以收集元数据并自动生成。

## 主要区域

- **知识库**：浏览已安装的知识包并打开 Markdown 文件。
- **源代码管理**：在发布前查看新增、修改和删除的文件。
- **Hub**：发现、安装、更新、导入、导出和发布知识包。
- **消息**：记录发布申请、批准与拒绝通知。
- **聊天**：使用已启用知识包和可选的 `@` 引用回答问题。
- **设置**：配置模型服务、Hub 连接、账户与本地存储。

## 本地优先

知识包保存在你的电脑上。无需登录即可阅读、编辑、导入、导出和检索。Hub 是
可选服务，用于共享目录、发布、受限知识包访问和审核通知。

## 已启用知识

已启用的知识包会参与聊天的全局检索。停用后仍可阅读，但不会参与检索，直到再次
启用。明确的 `@` 引用可将检索范围缩小到选定的已启用文件或文件夹。

## 版本与发布

Nest 为每个知识包保留一个已安装版本。已发布版本不可修改：请先更改本地文件，
选择更高的语义化版本号，提交该版本，并等待管理员批准或拒绝。
