# Nest 工作原理

Nest 使用普通文件夹和 Markdown 文件保存知识。已安装的知识包包含
`pack.json`，但从文件夹导入前无需手动创建它；Nest 可以收集元数据并自动生成。

## 基本使用流程

1. 通过 **Hub** 查找共享知识包，或从文件夹、ZIP 导入。
2. 在**资源管理器**中浏览已安装的知识包并阅读 Markdown 文件。
3. 需要改进或创建知识时，在本地编辑。
4. 导出 ZIP 直接分享，或通过 Hub 发布经过审核和版本管理的内容。

## 本地优先

知识包保存在你的电脑上。无需登录即可阅读、编辑、导入、导出和检索。Hub 是
用于共享目录、发布、受限知识包访问和审核通知的服务。

## 编辑与分享使用的区域

- **源代码管理**：在发布前查看新增、修改和删除的文件。
- **消息**：记录发布申请、批准与拒绝通知。
- **设置**：管理 Hub、账户、本地存储和可选的聊天配置。

## 版本与发布

Nest 为每个知识包保留一个已安装版本。已发布版本不可修改：请先更改本地文件，
选择更高的语义化版本号，提交该版本，并等待管理员批准或拒绝。

## 可选的聊天功能

聊天可使用已启用知识包和 `@` 引用回答问题。停用知识包不会删除内容，仍然可以
阅读，但在重新启用前不会参与普通聊天检索。
