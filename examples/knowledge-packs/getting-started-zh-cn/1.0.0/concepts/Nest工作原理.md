# Nest 工作原理

Nest 使用普通文件夹中的 Markdown 文件保存知识，并将其组织成知识包。知识包包含
`pack.json`，但你无需手动创建——从文件夹导入时 Nest 会自动生成。

## 主要区域

- **资源管理器**：浏览已安装的知识包并打开 Markdown 文件。
- **源代码管理**：查看从 Hub 安装且可编辑的知识包变更。本地知识包提交发布申请后，
  会在审核期间暂时显示在这里。
- **Hub**：查找、安装、更新、导入、导出和发布知识包。
- **消息**：记录发布申请、批准与拒绝通知。
- **聊天**：使用已启用知识包和 `@` 引用回答问题。
- **设置**：配置 Hub、账户、存储和聊天模型。

## 本地优先

已安装的知识包保存在你的电脑上。无需登录即可阅读、编辑、导入、导出和检索。Hub
是可选的，用于共享目录、发布、受限知识包访问和审核通知。

## 版本

Nest 为每个知识包保留一个已安装版本。发布新版本或提交实时补丁时，需要填写说明
变更内容的提交消息，然后等待审核通过。
