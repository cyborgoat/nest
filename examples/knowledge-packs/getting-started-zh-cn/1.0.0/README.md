# Nest 快速入门

欢迎使用 Nest。Nest 是一个本地优先的工作空间，可用于阅读、编辑、共享
Markdown 知识包，并基于知识内容进行对话。

## 按顺序学习

1. [前 10 分钟](guides/first-10-minutes.md)
2. [了解 Nest 的工作方式](concepts/how-nest-works.md)
3. [配置设置与 Hub 账户](guides/settings-and-account.md)
4. [管理知识库与知识包](guides/library-and-packs.md)
5. [从文件夹导入知识包](guides/import-from-folder.md)
6. [从 ZIP 导入知识包](guides/import-from-zip.md)
7. [从 Hub 安装知识包](guides/import-from-hub.md)
8. [编辑 Markdown 与使用源代码管理](guides/editing-and-source-control.md)
9. [使用聊天与 `@` 引用](guides/chat-and-references.md)
10. [导出、发布与查看消息](guides/publishing-and-messages.md)
11. [排查常见问题](guides/troubleshooting.md)

完成教程后，你将能够配置模型服务、选择参与检索的知识、创建与编辑知识包、
审查本地变更、通过 Hub 发布新版本、跟进审核意见，并获得有文件依据的回答。

此知识包会在首次启动时自动复制到本地知识目录。它与普通本地知识包相同，可以
编辑、重命名、导出、发布或删除。主动删除后，Nest 不会在每次启动时重新安装。
