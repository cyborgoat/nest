# Nest 快速入门（简体中文）

欢迎使用 Nest。Nest 是一个本地优先的工作空间，可用于阅读、编辑、共享
Markdown 知识包。

## 将知识添加到 Nest

先阅读[前 10 分钟](guides/前十分钟.md)，再根据知识目前所在的位置选择：

- [连接团队 Hub](guides/设置与账户.md)，然后
  [查找并安装已发布知识包](guides/从Hub安装.md)
- [从本机文件夹导入 Markdown](guides/从文件夹导入.md)
- [导入他人分享的知识包 ZIP](guides/从ZIP导入.md)

Hub URL 需要由团队提供。浏览共享目录需要连接 Hub，但导入本机文件夹或 ZIP 不需要。

安装或导入后，请阅读[知识库与知识包](guides/知识库与知识包.md)，了解如何打开、
整理、更新、导出或删除知识包。

## 编辑与分享

完成本指南后，你将能够查找团队共享的知识，将本地 Markdown 添加到 Nest，阅读和
管理已安装的知识包，并通过 ZIP 或 Hub 分享自己的内容。编辑、发布审核和聊天功能
可在需要时继续学习。

此知识包会在首次启动时自动复制到本地知识目录。它与普通本地知识包相同，可以
编辑、重命名、导出、发布或删除。主动删除后，Nest 不会在每次启动时重新安装。
