# Nest 快速入门（简体中文）

## 什么是 Nest？

Nest 是一个本地优先的知识工作空间，用于集中管理来自不同部门的知识包、配套图片和
其他基于 Markdown 的内容。使用 Nest 后，人们不必再记住某个文件究竟位于哪个网站、
网盘或聊天记录中，而可以在同一处查找、阅读、维护和分享所需知识。

桌面应用会将已安装知识保存在本机。团队还可以选择部署 **Hub**，提供共享目录，让
用户查找已发布的知识包、安装指定版本、获取更新，并在获得权限后访问受限内容。

## 为什么需要 Nest？

知识分散在不同网站和工具中时，不仅难以查找，也容易产生重复副本。用户往往无法确认
哪个版本最新、谁有权查看，以及某份内容是否代表组织的正式立场。

Nest 为团队提供：

- **统一的知识入口**：将跨部门的文档、图片和可共享资料组织成便于查找的知识包。
- **清晰的版本管理**：通过不可变的版本化发布，让读者知道安装的是哪个版本，并可
  主动更新。
- **可信的正式发布**：Hub 审核机制让授权审核者在发布前批准包含正式文档、设计指南
  和公告的知识包。
- **受控或直接分享**：通过 Hub 权限管理受限知识包，也可导出便携 ZIP 分享给指定
  对象。
- **可靠的本地访问**：即使 Hub 暂时不可用，已安装的知识包仍可阅读。

Nest 可以减少人们在多个互不相连的信息源之间来回切换的时间，并提供更清晰、可靠的
共享知识来源。

## 如何使用 Nest

1. **添加知识**：从团队 Hub 安装已发布知识包，或导入 Markdown 文件夹、Nest
   知识包 ZIP。
2. **查找并阅读**：打开**资源管理器**，展开知识包并选择文档。
3. **维护内容**：在本地编辑 Markdown，并在**源代码管理**中检查修改。
4. **分享内容**：导出 ZIP 直接分享，或向 Hub 发布新版本以接受审核并受控分发。
5. **保持最新**：Hub 出现较新的已批准版本时，选择安装更新。
