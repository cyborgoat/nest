# Nest 快速入门（简体中文）

Nest 是一个本地优先的知识工作空间，用于阅读、编辑和分享 Markdown 知识包。已安装
的知识包保存在本机；团队还可以选择部署 **Hub**，让用户查找、安装和发布共享知识包。

## 主要按钮在哪里

- 顶部栏右上角提供 **Hub**、**Messages**、**Settings** 和 **Chat**。
- 最左侧的窄活动栏提供 **Explorer**、**Source Control** 和 **Under Review**。
  如果只看到图标，把鼠标停在图标上即可看到对应的英文名称。
- 使用 **Explorer** 展开知识包并打开文件；使用 **Source Control** 查看修改和发布；
  使用 **Under Review** 查看正在审核的发布申请。

本教程会保留应用界面实际显示的英文按钮名称，方便你直接找到对应按钮。
