# 从 ZIP 导入知识包

当他人共享可移植 Nest 知识包，或在电脑之间迁移知识包时使用 ZIP。

## 压缩文件结构

ZIP 导入不会显示元数据表单，因此知识包根目录必须包含有效的 `pack.json` 和至少
一个 Markdown 文件。

```text
my-pack/
  pack.json
  README.md
  guides/
    first-topic.md
```

`id` 必须与知识包文件夹名称一致，`version` 必须是 `1.0.0` 之类的语义化版本。

## 导入步骤

1. 打开 **Hub**，选择 **导入**。
2. 选择 **导入知识包 ZIP**。
3. 拖入 ZIP 或浏览选择文件。
4. 选择 **导入 ZIP**。
5. 如果相同知识包已安装，确认替换。

Nest 每个知识包 ID 只保留一个版本，只有确认后才会替换。建议使用 Nest 的
**导出 ZIP** 操作生成结构正确的压缩文件。
