# 从 ZIP 导入

当他人共享可移植 Nest 知识包，或在电脑之间迁移知识包时使用 ZIP。

## 快速导入

1. 打开 **Hub**，选择 **导入**。
2. 选择 **导入知识包 ZIP**。
3. 拖入 ZIP 或浏览选择文件。
4. 如果 ZIP 没有 `pack.json`，请检查自动填写的 ID、名称、版本和可选描述，再点击
   **创建知识包**，由 Nest 生成元数据。
5. 如果 ZIP 已包含 `pack.json`，请选择 **导入 ZIP**。
6. 如果相同知识包已安装，确认替换。

Nest 每个知识包 ID 只保留一个版本，只有确认后才会替换。打开**资源管理器**即可找到
并阅读导入的知识包。

## 有无知识包元数据均可导入

使用 Nest **导出 ZIP** 生成的文件已包含 `pack.json`，可以直接导入。普通 ZIP
如果没有 `pack.json`，Nest 会根据压缩文件名或顶层文件夹自动填写名称和 ID，将版本
默认为 `1.0.0`，并允许你在导入前修改。

两种 ZIP 都必须至少包含一个 Markdown 文件。Nest 会在安装副本中生成
`pack.json`，原始 ZIP 保持不变。
