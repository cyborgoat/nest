# 从 ZIP 导入

当他人共享可移植 Nest 知识包，或在电脑之间迁移知识包时使用 ZIP。

## 快速导入

1. 打开 **Hub**，选择 **导入**。
2. 选择 **导入知识包 ZIP**。
3. 拖入 ZIP 或浏览选择文件。
4. 选择 **导入 ZIP**。
5. 如果相同知识包已安装，确认替换。

Nest 每个知识包 ID 只保留一个版本，只有确认后才会替换。打开**资源管理器**即可找到
并阅读导入的知识包。

## 哪些 ZIP 可以导入？

最简单可靠的是使用 Nest **导出 ZIP** 操作生成的文件。手动创建的压缩文件必须
包含一个知识包文件夹、其 `pack.json` 以及至少一个 Markdown 文件。如果你只有普通
Markdown 文件夹，请改用[从文件夹导入](从文件夹导入.md)，Nest 会为你创建知识包
信息。
