# 故障排查

## 文件夹或 ZIP 无法导入

- 文件夹至少需要一个 Markdown 文件，不要求包含 `pack.json`；确认知识包信息后，
  Nest 会自动创建。
- ZIP 至少需要一个 Markdown 文件。如果缺少 `pack.json`，请检查自动填写的知识包
  信息，再点击**创建知识包**。
- 如果 ZIP 中的 `pack.json` 无效，请修正该文件，或将其删除后使用 Nest 自动生成的
  知识包信息重新导入。
- 如果相同知识包已安装，需要保留时请先导出副本，再确认替换。

## Hub 无法连接或无法安装知识包

- 确认设置中的 Hub URL 与团队提供的地址一致。
- 查看连接状态后重试。
- 如果知识包受限，请先登录。
- 服务仍不可用时，请联系 Hub 管理员。已安装知识包和本地导入、阅读、编辑、导出
  不受影响。

## 发布失败

- 确认 `pack.json.id` 与文件夹一致，版本是有效 SemVer 且未发布过。
- 确认已登录正确的 Hub 账户并拥有发布权限。
- 等待已有待审核申请处理完毕。

## 本地修改状态过期

保存编辑器后刷新源代码管理。远程审核获批后，刷新并选择 **与远程合并** 来更新基线。

## 本地图片无法显示

使用相对 Markdown 文件的路径以及 PNG、JPEG、GIF、WebP、SVG 或 BMP 等支持格式，
并检查拼写和大小写。

## 可选聊天功能失败或回答较弱

- 检查模型 URL、API 密钥和模型名。
- 确认相关知识包已启用且索引完成。
- 使用范围更小的 `@` 引用。
- 查看引用并用更清晰的限制重新提问。
