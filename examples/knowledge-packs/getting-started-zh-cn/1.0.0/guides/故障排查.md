# 故障排查

## Hub 离线

- 检查设置中的 Hub URL 与协议。
- 在浏览器打开 Hub 健康检查地址。
- 确认 Hub 进程和反向代理正在运行。
- 本地阅读、编辑、导入、导出和聊天仍可使用。

## 管理后台登录后又返回登录页

如果登录返回 `201` 但页面立即退出，请更新 Hub 以支持仅 HTTP 的内部部署，或改用
HTTPS。只有 HTTPS 请求才会使用 `Secure` Cookie。

## 聊天失败或回答较弱

- 检查模型 URL、API 密钥和模型名。
- 确认相关知识包已启用且索引完成。
- 使用范围更小的 `@` 引用。
- 查看引用并用更清晰的限制重新提问。

## 导入或发布失败

- 文件夹导入至少需要一个 Markdown 文件；`pack.json` 可选。
- ZIP 导入必须只包含一个知识包及其 `pack.json`。
- 确认 `pack.json.id` 与文件夹一致，版本是有效 SemVer 且未发布过。
- 等待已有待审核申请处理完毕。

## 本地修改状态过期

保存编辑器后刷新源代码管理。远程审核获批后，刷新并选择 **与远程合并** 来更新基线。

## 本地图片无法显示

使用相对 Markdown 文件的路径以及 PNG、JPEG、GIF、WebP、SVG 或 BMP 等支持格式，
并检查拼写和大小写。
