# 发布知识包与查看消息

根据分享方式选择：

| 目标                           | 使用方式     |
| ------------------------------ | ------------ |
| 直接向他人发送副本             | **导出 ZIP** |
| 在团队知识包目录中提供一个版本 | 发布到 Hub   |

## 分享 ZIP

在已安装知识包操作中选择 **导出 ZIP**，然后把文件发送给其他 Nest 用户。对方可
通过 **Hub → 导入 → 导入知识包 ZIP** 添加。导出不需要账户或 Hub 连接。

## 发布到 Hub

你需要连接 Hub、登录拥有发布权限的账户，并确保该知识包没有正在审核的申请。

1. 打开并阅读准备分享的内容。
2. 打开**源代码管理**，审查每项本地修改。
3. 使用知识包的**发布**操作。
4. 选择**新版本**以发布新的语义版本，或选择**实时补丁**以替换某个未撤下版本的
   文件。发布新版本时，Nest 会自动填写 Hub 最近发布版本的描述。
5. 打开**审核中**或**消息**查看结果。

版本命名、文件兼容性和完整的发布前检查，请参阅
[知识包发布规则](发布规则.md)。

## 提交之后

每个知识包同时只能有一个申请处于审核中：

- **已批准**：该版本会出现在 Hub。请在消息或源代码管理中选择 **与远程合并**，
  完成本地审核状态同步。
- **已拒绝**：打开消息阅读审核意见。本地修改会保留，可按要求修改后再次发布。

合并获批版本会更新比较基线，但不会覆盖提交后继续进行的编辑；这些新修改仍会显示
在源代码管理中。

获批的实时补丁显示为 `vX.Y.Z · 补丁 N`。已安装该语义版本的用户会看到
**有可用补丁**，可选择**同步补丁**。如果源代码管理中存在本地修改，Nest 会阻止
同步；请先提交或丢弃修改。新语义版本和实时补丁可以同时显示。
