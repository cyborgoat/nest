# 发布知识包与查看消息

## 导出副本

在已安装知识包操作中选择 **导出 ZIP**。Nest 会将元数据和内容打包，可在其他电脑
导入。

## 准备发布

1. 在源代码管理中审查每项修改。
2. 遵循[知识包发布规则](发布规则.md)。
3. 使用语义化版本：修复用补丁版本，新增内容用次版本，不兼容结构变更用主版本。
4. 检查链接、图片、Markdown 渲染和 README。

## 提交

选择发布操作，填写下一版本和描述后上传。Hub 会验证路径、元数据、大小、Markdown
内容及版本唯一性，然后创建待审核申请。

每个知识包同时只能有一个待审核申请。仅提交不会推进本地比较基线。

## 跟进审核

- **已批准**：版本出现在 Hub，待处理标记清除，批准版本成为新基线。
- **已拒绝**：待处理标记清除，本地修改保留，并显示拒绝标记。

源代码管理刷新可立即同步状态。消息页面记录提交、批准和拒绝事件；未读消息会显示
圆点。阅读管理员意见、完成修改并选择有效的新版本后可再次提交。
