# 发布知识包与查看消息

| 目标 | 使用方式 |
| --- | --- |
| 直接向他人发送副本 | **导出 ZIP** |
| 在团队目录中提供一个版本 | **发布**到 Hub |

## 分享 ZIP

在知识包操作中选择**导出 ZIP**，把文件发送给其他 Nest 用户。对方可通过
**Hub → 导入 → 导入知识包 ZIP** 添加。导出不需要账户或 Hub 连接。

## 发布到 Hub

需要 Hub 连接、有发布权限的账户，并且该知识包没有正在审核的申请。

1. 对于从 Hub 安装的知识包，在**源代码管理**中审查每项修改。
2. 使用知识包的**发布**操作。
3. 选择**新版本**（发布新版本号）或**实时补丁**（替换现有版本的文件）。
4. 填写简洁的发布提交消息，说明本次变更。
5. 在**审核中**或**消息**中查看结果。

新知识包的首次发布通过审核后，提交者会成为该知识包的署名作者，并自动加入
维护者列表。Hub 知识包详情会显示作者和当前维护者；管理员可在管理后台中
分别修改作者归属和维护权限。

## 提交之后

- **审核中**：知识包会被锁定。已提交的变更会以只读方式保留在源代码管理中。原始
  提交者可以在**审核中**取消申请并解锁知识包。
- **已批准**：在消息或源代码管理中选择**与远程合并**同步基线。
- **已拒绝**：在消息中阅读审核意见，修改后可再次发布。

获批的实时补丁会显示为**有可用补丁**，选择**同步补丁**即可（源代码管理必须没有
本地修改）。
