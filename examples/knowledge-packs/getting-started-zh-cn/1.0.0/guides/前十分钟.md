# 开始使用：前 10 分钟

## 1. 浏览知识库

打开资源管理器侧栏，展开 `getting-started-zh-cn`，然后打开本文件。使用顶部
标签页在已打开的文档之间切换。

## 2. 配置聊天

打开 **设置 → 常规**，填写 OpenAI 兼容 API 的基础 URL、API 密钥和聊天模型名。
保存后打开聊天并提问：

```text
已启用和未启用的知识包有什么区别？
```

打开回答中的引用，查看哪些教程页面提供了依据。

## 3. 尝试 `@` 引用

在聊天输入框输入 `@`，选择本知识包或其中的指南：

```text
@getting-started-zh-cn/guides 如何发布知识包？
```

引用会保留为输入框内高亮的文本块，并将检索限制到所选目标。

## 4. 进行一次小修改

打开 Markdown 文件，进入编辑模式，修改并保存。打开源代码管理查看差异。你可以
保留修改，也可以丢弃修改以恢复到上一次同步版本。

## 5. 需要时连接 Hub

在设置中填写 Hub URL。公共知识包无需账户即可浏览。需要发布、接收审核消息或
访问受限知识包时，请在 **设置 → 账户** 登录。
