# 开始使用：前 10 分钟

第一个目标很简单：把有用的知识添加到 Nest，然后打开阅读。

## 1. 连接 Hub 以使用团队目录

如果要查找团队发布的知识包：

1. 向团队或 Hub 管理员获取 Hub URL。
2. 打开**设置**，在 **Hub URL** 中填写该地址。
3. 点击**测试连接**，确认状态显示 Hub 已连接。
4. 如果团队要求登录或知识包受限，请前往 **设置 → 账户** 登录。

从本机文件夹或 ZIP 导入时，可以跳过此步骤。

## 2. 确认知识来自哪里

打开 **Hub**，根据现有内容选择：

| 你现在有 | 选择 |
| --- | --- |
| 团队发布的知识包 | **浏览**，然后搜索并安装 |
| 包含 Markdown 的本机文件夹 | **导入 → 从文件夹创建** |
| 他人分享的 Nest 知识包 ZIP | **导入 → 导入知识包 ZIP** |

如果 Hub 允许，公共知识包无需账户即可浏览。从文件夹或 ZIP 导入不需要登录 Hub。

## 3. 添加一个知识包

- **来自 Hub**：搜索或浏览，打开知识包，选择版本，再点击 **安装**。
- **来自文件夹**：选择至少包含一个 `.md` 文件的文件夹，检查名称，再点击
  **创建知识包**。
- **来自 ZIP**：选择由 Nest 导出的 ZIP，再点击 **导入 ZIP**。

Nest 会把知识包复制到本地知识目录，原文件夹或 ZIP 保持不变。

## 4. 打开并阅读

打开**资源管理器**，展开刚添加的知识包，然后选择一个 Markdown 文件。顶部标签页可在
多个已打开的文档之间切换。Hub 离线后，已安装知识包仍可阅读。

需要更多说明时，请阅读：

- [从 Hub 安装](从Hub安装.md)
- [从文件夹导入](从文件夹导入.md)
- [从 ZIP 导入](从ZIP导入.md)

## 5. 准备好后分享知识

- 使用 **导出 ZIP**，直接向他人发送可移植副本。
- 登录 Hub 并使用**发布**，通过团队目录和审核流程共享版本。

完整流程请参阅[发布知识包与查看消息](发布与消息.md)。

## 可选：使用聊天提问

聊天是使用已安装知识的附加方式。阅读、导入、编辑、导出或发布知识包都不需要配置
模型。如需使用聊天，请先在**设置**中配置模型服务，再阅读
[聊天与文件引用](聊天与引用.md)。
