# 前 10 分钟

第一个目标很简单：把一个知识包添加到 Nest，然后打开阅读。

先认识位置：**Hub**、**Messages** 和 **Chat** 在顶部栏右上角；
**Explorer**、**Source Control**、**Under Review** 在最左侧活动栏，
**Account** 用户图标和 **Settings** 齿轮图标位于活动栏底部。只看到图标时，
把鼠标停在图标上即可查看英文名称。

## 1. 连接 Hub（可选）

只导入本机文件夹或 ZIP 时可跳过此步骤。

1. 向团队获取 Hub URL。
2. 打开 **Hub**，点击 **Configure Hub URL in Settings**。Nest 会打开
   **Settings** 并定位到 **Hub URL**。也可直接点击左下角的 Settings 齿轮。
3. 点击 **Test connection**。
4. 如果知识包受限，请点击左下角的 **Account** 用户图标登录。

## 2. 添加一个知识包

| 你现在有 | 操作 |
| --- | --- |
| 团队发布的知识包 | 右上角 **Hub → Browse**，然后点击 **Install** |
| 包含 Markdown 的本机文件夹 | **Hub → Import → Create from folder** |
| 他人分享的 Nest 知识包 ZIP | **Hub → Import → Import pack ZIP** |

Nest 会把知识包复制到本地知识目录，原文件夹或 ZIP 保持不变。详见
[从 Hub 安装](从Hub安装.md)、[从文件夹导入](从文件夹导入.md)或
[从 ZIP 导入](从ZIP导入.md)。

## 3. 打开并阅读

点击最左侧的 **Explorer**，展开新知识包，选择一个 Markdown 文件。Hub 离线后，已安装
知识包仍可阅读。

## 4. 准备好后分享

- **Export ZIP**：直接向他人发送可移植副本。
- **Publish**（需登录 Hub）：通过团队目录共享版本。

详见[发布知识包与查看消息](发布与消息.md)。

## 可选：使用聊天提问

点击右上角 **Chat** 使用已安装知识回答问题。请先在 **Settings** 中配置模型服务，再阅读
[聊天与文件引用](聊天与引用.md)。
