# 管理知识库与知识包

## 添加知识

根据知识包所在位置选择工作流：

- [从 Hub 安装](从Hub安装.md)：查找团队发布的知识。
- [从文件夹导入](从文件夹导入.md)：适用于电脑上的 Markdown；`pack.json`
  可选。
- [从 ZIP 导入](从ZIP导入.md)：适用于可移植知识包压缩文件。

Nest 为每个知识包 ID 保留一个已安装版本。

## 浏览与阅读

资源管理器侧栏显示已安装的知识包、文件夹和文件。展开知识包并打开 Markdown 文件即可
阅读。已打开的文件会显示在标签页中，方便同时查看多个主题。

## 更新、导出与删除

- **更新**安装更高版本的 Hub 发布。
- **导出**创建可移植 ZIP。
- **删除**移除本地副本及其聊天检索范围。

删除本地知识包不会删除 Hub 项目或已发布版本。

## 可选：选择聊天检索范围

可通过知识包操作启用或停用。已启用知识包可参与普通聊天检索；未启用知识包仍保留
在本地并可阅读。更改此设置不会删除内容。
