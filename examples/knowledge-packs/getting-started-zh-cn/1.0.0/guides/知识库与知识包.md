# 管理知识库与知识包

## 浏览与启用

资源管理器显示知识包文件夹和文件。通过知识包操作启用或停用：

- 已启用知识包可参与聊天检索；
- 未启用知识包仍保留在本地并可阅读；
- 更改启用状态不会删除内容。

## 添加知识包

根据知识包所在位置选择工作流：

- [从文件夹导入](从文件夹导入.md)：适用于电脑上的 Markdown；`pack.json`
  可选。
- [从 ZIP 导入](从ZIP导入.md)：适用于可移植知识包压缩文件。
- [从 Hub 安装](从Hub安装.md)：适用于已发布的共享知识包。

Nest 为每个知识包 ID 保留一个已安装版本。

## 更新、导出与删除

- **更新**安装更高版本的 Hub 发布。
- **导出**创建可移植 ZIP。
- **删除**移除本地副本及其聊天检索范围。

删除本地知识包不会删除 Hub 项目或已发布版本。
