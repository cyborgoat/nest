# 资源管理器与知识包

## 添加知识包

- [从 Hub 安装](从Hub安装.md) —— 团队发布的知识包。
- [从文件夹导入](从文件夹导入.md) —— 电脑上已有的 Markdown。
- [从 ZIP 导入](从ZIP导入.md) —— 可移植的知识包压缩文件。

Nest 为每个知识包 ID 保留一个已安装版本。

使用资源管理器的 **+** 按钮创建知识包时，Nest 会保留输入的显示名称，并自动生成
适合后续发布到 Hub 的 ID 和文件夹名称。中文字符会完整保留，拉丁字母转为小写，
标点和空格转为连字符。

## 浏览与阅读

资源管理器显示已安装的知识包及其文件。打开 Markdown 文件即可阅读；已打开的文件
会显示在标签页中。

右键点击知识包或文件夹可以导入 Markdown 文件和图片。也可以在可编辑的知识包之间
拖放文件或文件夹；拖动时目标文件夹会高亮，放下后项目会被移动而不是复制。
新建文件夹会立即显示在资源管理器中，即使内部为空也会保持可见。

## 更新、导出、删除

- **更新**安装更高版本的 Hub 发布。
- **导出**创建可移植 ZIP。
- **删除**移除本地副本（Hub 项目及已发布版本不受影响）。

## 聊天可见性（可选）

通过知识包操作启用或停用。已启用知识包可参与聊天检索；未启用知识包仍保留在本地
并可阅读。此设置不会删除内容。
