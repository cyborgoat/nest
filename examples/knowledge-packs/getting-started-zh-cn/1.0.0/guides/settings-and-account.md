# 设置与账户

## 模型连接

| 设置 | 用途 | 示例 |
| --- | --- | --- |
| LLM 基础 URL | OpenAI 兼容 API 地址 | `https://api.openai.com/v1` |
| API 密钥 | 该服务的凭据 | 由服务商提供 |
| 聊天模型 | 完成请求使用的模型 | 由服务商提供 |
| 字体大小 | 应用文字缩放 | `10pt` |
| 知识目录 | 保存本地知识包的文件夹 | 留空使用默认目录 |

只有使用聊天时才会访问模型服务。请妥善保管 API 密钥。

## Hub 与账户

将 **Hub URL** 设置为服务根地址，例如 `http://127.0.0.1:8787`。可在设置中测试
连接。通过 **设置 → 账户** 创建或登录账户。发布和受限内容需要账户；本地编辑、
本地聊天和公共下载不需要。

## 更改知识目录

选择新目录后，Nest 会要求选择：

- **迁移知识包**：验证复制到新目录后，删除旧目录中的知识包；
- **删除旧知识包并重新开始**：删除旧知识包，并在新目录安装中英文入门教程；
- **取消**：保持原目录不变。

新目标目录必须为空。Nest 只移动或删除受管理的知识包，不会删除旧目录中的其他
文件。
