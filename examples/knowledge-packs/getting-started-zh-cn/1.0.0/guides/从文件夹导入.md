# 从文件夹导入

当电脑上已有 Markdown 笔记或文档文件夹时使用此方式。

## 准备内容

- 至少包含一个 Markdown（`.md`）文件的文件夹。
- 清晰的知识包名称。

`pack.json` 是可选的。如果不存在，Nest 会根据文件夹名称生成初始信息，让你确认
知识包 ID、名称、版本和可选描述，然后在安装副本中自动生成 `pack.json`。

如果已有有效的 `pack.json`，Nest 会将其中的值作为表单默认值供你检查。

## 导入步骤

1. 打开 **Hub**，选择 **导入**。
2. 选择 **从文件夹创建**。
3. 选择包含 Markdown 文件的文件夹。
4. 检查生成或读取到的知识包信息。
5. 选择 **创建知识包**。

Nest 会将支持的 Markdown 和图片复制到本地知识目录，原始文件夹保持不变。

```text
my-notes/
  开始阅读.md
  guides/
    第一个主题.md
  images/
    diagram.png
```

安装副本还会包含生成的 `pack.json`。日后发布时请保持知识包 ID 稳定。
