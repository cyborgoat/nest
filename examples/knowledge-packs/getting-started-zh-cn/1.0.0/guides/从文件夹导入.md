# 从文件夹导入

当电脑上已有 Markdown 笔记或文档文件夹时使用此方式。

## 步骤

1. 将至少一个 Markdown（`.md`）文件放入文件夹。
2. 打开 **Hub → 导入 → 从文件夹创建**。
3. 选择该文件夹。
4. 检查建议的知识包名称和信息。
5. 选择 **创建知识包**。

Nest 会将文件复制到本地知识库，原始文件夹保持不变。打开**资源管理器**即可阅读
新知识包。

## 示例结构

```text
my-notes/
  开始阅读.md
  guides/
    第一个主题.md
  images/
    diagram.png
```

## 关于 `pack.json`

无需自己创建——Nest 会建议 ID、名称、版本和描述，并生成该文件。如果文件夹已有
`pack.json`，Nest 会将其用作表单初始值。
