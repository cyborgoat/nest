# 从文件夹导入

当电脑上已有 Markdown 笔记或文档文件夹时使用此方式。

## 快速导入

1. 将至少一个 Markdown（`.md`）文件放入文件夹。
2. 打开 **Hub**，选择 **导入**。
3. 选择 **从文件夹创建**。
4. 选择包含 Markdown 文件的文件夹。
5. 检查建议的知识包名称和信息。
6. 选择 **创建知识包**。

Nest 会将支持的 Markdown 和图片复制到本地知识目录，原始文件夹保持不变。打开
**资源管理器**即可找到并阅读新知识包。

```text
my-notes/
  开始阅读.md
  guides/
    第一个主题.md
  images/
    diagram.png
```

文件夹可以按照最方便读者查找的方式组织。只要目标文件一并导入，相对链接和图片
仍可正常工作。

## 关于知识包信息

无需自己创建 `pack.json`。Nest 会建议 ID、名称、版本和可选描述，经你确认后在
安装副本中创建所需元数据。如果文件夹已有有效元数据，Nest 会将其用作表单初始值。

日后要在同一个 Hub 条目下发布更新时，请保持知识包 ID 不变。
