# 从 Hub 安装

Hub 是查找团队已发布知识包的最快方式。

## 先连接 Hub

1. 向团队或 Hub 管理员获取 Hub URL。
2. 打开**设置**，在 **Hub URL** 中填写该地址。
3. 点击**测试连接**，确认状态显示 Hub 已连接。
4. 如果团队要求登录或知识包受限，请前往 **设置 → 账户** 登录。

公共知识包可能不需要账户，但浏览目录前仍需配置 Hub URL。

## 查找并安装

1. 打开 **Hub → 浏览**。
2. 按名称搜索，或浏览知识包目录。
3. 打开知识包，阅读描述并查看可用版本。
4. 选择版本并点击 **安装**。
5. 打开**资源管理器**，展开已安装的知识包，再选择文件阅读。

## 更新与版本

Nest 每个知识包 ID 只安装一个版本。更新、降级或替换都会先要求确认。Hub 离线后
已安装内容仍可阅读，但受限下载和后续更新需要有效连接与权限。

维护者也可以在不创建新语义版本的情况下发布经过审核的实时补丁。看到
**有可用补丁**时，选择**同步补丁**即可替换当前版本的文件。同步前，源代码管理
必须没有本地修改。

如果安装会替换本地文件，Nest 会先要求确认。需要保留当前内容时，请先导出可移植
副本。
