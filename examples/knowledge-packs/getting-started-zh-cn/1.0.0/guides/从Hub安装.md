# 从 Hub 安装

使用 Hub 查找并安装团队发布的知识包。

## 连接 Hub

1. 打开 **设置**。
2. 填写 Hub URL。
3. 受限知识包需要登录；公共知识包可在 Hub 允许时匿名浏览。

## 安装步骤

1. 打开 **Hub → 浏览**。
2. 搜索或浏览知识包。
3. 查看可用版本。
4. 选择需要的版本并点击 **安装**。

Hub 下载的完整知识包已包含 `pack.json`，无需自行创建元数据。

## 本地名称冲突

如果远程知识包与本地知识包同名，Nest 会在下载前警告。继续操作会替换本地知识包
及其文件；若需保留本地内容，请先导出或重命名。

## 更新与版本

Nest 每个知识包 ID 只安装一个版本。更新、降级或替换都会先要求确认。Hub 离线后
已安装内容仍可阅读，但受限下载和后续更新需要有效连接与权限。
