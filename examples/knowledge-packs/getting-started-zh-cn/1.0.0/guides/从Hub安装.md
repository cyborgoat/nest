# 从 Hub 安装

## 连接 Hub

1. 向团队获取 Hub URL，在**设置**中填写。
2. 点击**测试连接**。
3. 如果知识包受限，请前往 **设置 → 账户** 登录。

## 查找并安装

1. 打开 **Hub → 浏览**。
2. 搜索或浏览目录。
3. 打开知识包，选择版本。
4. 点击**安装**，再从**资源管理器**打开阅读。

## 更新

Nest 每个知识包 ID 只安装一个版本。安装更高版本会更新知识包；选择较低版本会
要求确认降级——无论哪种情况，替换本地文件前 Nest 都会先确认。看到**有可用补丁**
时，选择**同步补丁**（同步前源代码管理必须没有本地修改）。

Hub 离线后已安装知识包仍可阅读；更新需要有效连接。
