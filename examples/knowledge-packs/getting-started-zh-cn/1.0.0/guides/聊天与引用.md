# 聊天与文件引用

## 在已启用知识中提问

没有引用的提示词会搜索所有已启用知识包。请明确结果、受众、格式与限制条件。

## 使用 `@` 聚焦

输入 `@`，搜索并选择文件或文件夹。引用会作为带背景色的 `@文件名` 文本块保留
在输入框中，也会在上方显示简洁摘要。可以组合多个引用。

```text
@getting-started-zh-cn/guides/编辑与源代码管理.md
请给我一份发布前审查修改的检查清单。
```

文件夹适合一个主题，文件适合最精确的回答。对引用块按退格键会整体删除引用。

## 检查引用来源

检索来源会与回答一起显示。当回答不完整、意外或范围过大时，请打开引用核对，
重新描述问题或使用更精确的引用。

## 管理长对话

聊天会话可在标签页中打开、重命名、置顶、归档和删除。新会话会在第一轮回答后
自动生成主题标题。回答完成后视图会停留在最新消息。

## 改善回答

1. 只启用相关知识包。
2. 每次提出一个明确任务。
3. 说明受众与输出格式。
4. 精确问题使用 `@`。
5. 根据引用核对重要内容。
