# 应用设置与 Hub 账户

## 连接团队 Hub

打开共享 Hub 目录前：

1. 向团队或 Hub 管理员获取 Hub URL。
2. 打开**设置**，在 **Hub URL** 中填写该地址。
3. 点击**测试连接**。
4. 状态显示 Hub 已连接后再继续。

连接后可以浏览公共知识包。导入文件夹或 ZIP，以及阅读、编辑和导出本地知识包，
不需要连接 Hub。

## 需要时登录账户

通过 **设置 → 账户** 创建或登录账户。发布和访问受限内容需要账户；本地操作和公共
知识包下载不需要。退出账户不会删除已安装知识包。

## 阅读与存储设置

- **字体大小**：调整应用文字缩放。
- **知识目录**：选择保存本地知识包的文件夹；留空时使用应用默认目录。

## 更改知识目录

选择新目录后，Nest 会要求选择：

- **迁移知识包**：验证复制到新目录后，删除旧目录中的知识包；
- **删除旧知识包并重新开始**：删除旧知识包，并在新目录安装中英文入门教程；
- **取消**：保持原目录不变。

新目标目录必须为空。Nest 只移动或删除受管理的知识包，不会删除旧目录中的其他
文件。

## 可选：为聊天连接模型

聊天需要 OpenAI 兼容 API 的基础 URL、API 密钥和模型名。查找、导入、阅读、编辑、
导出或发布知识包都不需要这些设置。只有使用聊天时才会访问模型服务，请妥善保管
API 密钥。
