# 设置与账户

## 连接 Hub

1. 向团队获取 Hub URL。
2. 打开**设置**，在 **Hub URL** 中填写该地址。
3. 点击**测试连接**。

Hub 连接是可选的——导入文件夹或 ZIP，以及阅读、编辑和导出本地知识包，都不需要
连接 Hub。

## 登录

通过 **设置 → 账户** 创建或登录账户。发布和访问受限内容需要账户，本地操作和公共
下载不需要。退出账户不会删除已安装知识包。

## 存储设置

- **字体大小**：调整应用文字缩放。
- **知识目录**：选择保存知识包的文件夹（留空使用默认目录）。更改为新的空目录后，
  Nest 会询问是迁移当前知识包，还是删除后重新开始并安装默认教程包。

## 聊天模型（可选）

聊天需要 OpenAI 兼容 API 的基础 URL、API 密钥和模型名，在**设置**中配置。仅在
使用聊天时才会用到这些设置。
