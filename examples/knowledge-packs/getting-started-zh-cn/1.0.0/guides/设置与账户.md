# 设置与账户

**Settings** 是最左侧活动栏底部的齿轮图标，页面从上到下依次是 Hub、
Knowledge vault、Appearance、LLM、Network 和 Local index。齿轮上方的用户图标会
打开独立的 **Account** 页面，用于 Hub 登录和账户资料。

## 连接 Hub

1. 向团队获取 Hub URL。
2. 打开 **Hub**，点击 **Configure Hub URL in Settings**。Nest 会直接定位到
   **Hub URL**。也可打开 Settings 齿轮，在页面顶部找到该字段。
3. 点击 **Test connection**。

配置和连接恢复操作只在 **Browse** 空状态中显示一次；Hub 连接后，可选的账户登录
使用紧凑的蓝色提示。

Hub 连接是可选的——导入文件夹或 ZIP，以及阅读、编辑和导出本地知识包，都不需要
连接 Hub。

## 登录

通过左下角独立的 **Account** 页面创建或登录账户。发布和访问受限内容需要账户，本地操作
和公共下载不需要。创建账户时需输入两次密码，Nest 会在提交前确认两次输入一致。
退出账户不会删除已安装知识包。如果尚未配置 Hub，Account 会显示 **Configure Hub** 操作，
并直接打开 Settings 中的 Hub URL 字段。

## 存储设置

- **Font size**：调整应用文字缩放。
- **Knowledge directory**：选择保存知识包的文件夹（留空使用默认目录）。更改为新的空目录后，
  Nest 会询问是迁移当前知识包，还是删除后重新开始并安装默认教程包。

**Local index** 状态和手动 **Sync index** 操作位于 **Settings** 页面最底部。

## 聊天模型（可选）

聊天需要 OpenAI 兼容 API 的基础 URL、API 密钥和模型名，在 **Settings** 中配置。仅在
使用聊天时才会用到这些设置。
