# Getting Started with Nest

Welcome to Nest, a local-first workspace for reading, editing, sharing, and
chatting with Markdown knowledge packs.

## What you will learn

By the end, you will be able to configure a model provider, choose which
knowledge is active, create and edit a pack, review local changes, publish a
new version through Hub, follow review feedback, and get answers grounded in
specific files.

This pack is installed automatically on first launch. You may remove it like
any other pack; Nest will not reinstall it after you intentionally remove it.
