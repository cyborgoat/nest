# Chat and `@` References

## Ask across active packs

A prompt without references searches all active packs. Be specific about the
desired result, audience, format, and constraints.

## Focus with `@`

Type `@`, search for a file or folder, and choose it. The reference appears as
a pill inside the composer. Multiple references can be combined.

```text
@getting-started/guides/editing-and-source-control.md
Give me a checklist for reviewing edits before publishing.
```

Use a folder for a topic and a file for the narrowest answer. Remove a pill when
it is no longer relevant.

## Check citations

Retrieved sources appear with the assistant response. Open citations when an
answer seems incomplete, surprising, or too broad. Rephrase the prompt or use a
more precise reference when the wrong sources were selected.

## Manage long conversations

Chat sessions can be opened in tabs, renamed, pinned, archived, and deleted.
Scrolling away from a streaming response keeps your reading position; use the
jump-to-latest control to resume following new output.

## Improve answers

1. Keep only relevant packs active.
2. Ask one concrete task at a time.
3. Include the intended audience and output format.
4. Use `@` for precise questions.
5. Verify important statements against citations.
