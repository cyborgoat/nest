# Install a Pack from Hub

## Connect Hub

1. Ask your team for the Hub URL. Open **Hub**, then select **Configure Hub URL
   in Settings** to jump directly to the field.
2. Select **Test connection**.
3. Sign in under **Settings → Account** if the pack is restricted.

## Install a pack

1. Open **Hub → Browse**.
2. Search or browse the catalog.
3. Open a pack and choose a version.
4. Select **Install**, then open it from **Explorer**.

## Updates

Nest keeps one installed version per pack ID. Installing a newer release
updates it; picking an older one asks you to confirm the downgrade — either
way, Nest asks first if it would replace local files. When **Patch available**
appears, select **Sync patch**. Nest merges non-conflicting local work and asks
you to choose the local or approved version for any conflicting file.

Installed packs stay readable if Hub goes offline; updates need a working
connection. If a configured Hub cannot connect, use **Retry connection** or
**Open Hub settings** in the red connection notice.
