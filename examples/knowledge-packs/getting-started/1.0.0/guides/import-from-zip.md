# Import a Pack from a ZIP

Use a ZIP when someone shared a portable Nest pack with you, or you're moving
a pack between computers.

## Steps

1. Open **Hub → Import → Import pack ZIP**.
2. Drag in the ZIP or browse for it.
3. If it has no `pack.json`, review the prefilled details and select
   **Create pack**. Otherwise select **Import ZIP**.
4. Confirm replacement if the same pack is already installed.

Nest keeps one installed version per pack ID and leaves the original ZIP
unchanged. A ZIP made with **Export ZIP** already has `pack.json`; an ordinary
ZIP just needs at least one Markdown file — Nest fills in the rest.
