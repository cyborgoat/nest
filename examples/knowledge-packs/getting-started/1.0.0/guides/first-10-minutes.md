# First 10 Minutes

Your first goal: bring one knowledge pack into Nest and open it.

## 1. Connect Hub (optional)

Skip this if you're only importing a local folder or ZIP.

1. Ask your team for the Hub URL.
2. Open **Settings** and enter it under **Hub URL**.
3. Select **Test connection**.
4. Sign in under **Settings → Account** if the pack is restricted.

## 2. Add a pack

| You have | Do this |
| --- | --- |
| A pack published by your team | **Hub → Browse**, then install |
| A folder of Markdown files | **Hub → Import → Create from folder** |
| A Nest pack ZIP | **Hub → Import → Import pack ZIP** |

Nest copies the pack into its local knowledge directory; your source folder or
ZIP is left unchanged. See [Install from Hub](import-from-hub.md),
[Import from a folder](import-from-folder.md), or
[Import from a ZIP](import-from-zip.md) for details.

## 3. Open and read it

Open **Explorer**, expand the new pack, and select a Markdown file. Installed
packs stay available even when Hub is offline.

## 4. Share when you're ready

- **Export ZIP** sends a portable copy directly to someone.
- **Publish** (signed in to Hub) shares a version through your team's catalog.

See [Exporting, publishing, and messages](publishing-and-messages.md).

## Optional: ask Chat

Chat answers questions using installed packs. Configure a model provider in
**Settings**, then see [Chat and `@` references](chat-and-references.md).
