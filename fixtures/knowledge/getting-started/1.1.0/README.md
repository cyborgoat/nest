# Getting Started with Nest

Nest is a desktop knowledge workspace. It keeps domain knowledge in a folder tree, lets you attach personal notes, and answers questions using retrieval over your local library.

## What you can do

- Browse downloaded knowledge packs as folders and Markdown files
- Read knowledge without editing source content
- Add personal notes tied to each file
- Ask questions in chat with automatic or scoped retrieval

## Knowledge packs

Packs are immutable after download. Updates replace a pack version as a whole rather than merging file edits.
