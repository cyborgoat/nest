# Getting Started with Nest

Nest is a desktop knowledge workspace. It keeps domain knowledge in Markdown packs, lets you browse them locally, and answers questions with retrieval over packs you mark **active**.

## What you can do

- Browse downloaded knowledge packs as folders and Markdown files
- Read knowledge without editing source content
- Activate or deactivate packs in the Library (inactive packs stay readable but leave chat)
- Ask questions in chat over active packs, or `@`-mention files and folders to focus retrieval

## Knowledge packs

Packs are immutable after download. Updates replace a pack version as a whole rather than merging file edits.
