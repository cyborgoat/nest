# Asking Questions

Open the Chat panel and type a natural-language question about your library.

## Tips

1. Prefer specific questions over broad ones.
2. Select folders or files when you know the domain.
3. Open citations after an answer to jump back to the source Markdown.

## Example

> How does Nest keep knowledge files immutable?

That question should retrieve vault documentation and explain that notes are stored separately from the Markdown pack.
