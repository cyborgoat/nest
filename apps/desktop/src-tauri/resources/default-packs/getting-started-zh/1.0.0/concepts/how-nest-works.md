# 如何使用 Nest

Nest 用于浏览知识包并基于你选择的内容进行问答.

## 主要区域

1. Library: 浏览已安装知识包并打开文件.
2. Chat: 提问, 并可按文件或文件夹聚焦.
3. Hub: 下载、更新、导入、导出、删除知识包.
4. Settings: 配置模型连接与应用偏好.

## 日常使用流程

1. 打开 Library, 激活你要使用的知识包.
2. 阅读文件, 了解已有内容.
3. 打开 Chat 并提问.
4. 需要时使用 `@` 精确聚焦.
5. 在 Hub 中按需管理知识包.

## 激活与未激活

- 已激活知识包会用于 Chat 回答.
- 未激活知识包仍可阅读, 但不会参与 Chat 回答.

## `@` 聚焦

在 Chat 中输入 `@`, 选择文件或文件夹, 让回答聚焦在指定主题.

## 离线友好

- 你可以随时阅读已安装知识包.
- 即使不连接 Hub, 也可以导入本地 `.zip` 知识包.
