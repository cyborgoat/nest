# 故障排查

## Hub 显示离线

- 在 Settings 中确认 Hub Base URL 是否正确.
- 确认 Hub 进程是否正在运行.
- 在浏览器中打开 Hub Base URL, 检查是否有响应.
- 即使没有 Hub, 你仍然可以使用本地知识包.

## Chat 回答不相关或质量较弱

- 确认相关知识包已激活.
- 使用 `@` 聚焦文件或文件夹.
- 在知识包变更后稍等片刻再提问.
- 检查模型地址、模型名称、API key 是否配置正确.

## 本地图片不显示

- 确认路径相对于当前 markdown 文件是否正确.
- 确认扩展名受支持 (`png`, `jpg`, `jpeg`, `gif`, `webp`, `svg`, `bmp`).
- 确认图片体积不过大 (过大图片可能被拒绝).

## 导入失败

- zip 内必须包含 `pack.json`.
- `pack.json.id` 应与顶层文件夹名称一致.
- `pack.json.version` 建议使用常规版本号, 如 `1.0.0`.

## 我删除了预装 getting-started 知识包

- 这是预期行为, 会对当前安装数据永久生效.
- 删除后 Nest 不会自动重新安装.
- 如果有可用副本, 可通过 Hub 或 Import 重新安装.
