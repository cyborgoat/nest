# 资料库与知识包工作流

## Library 的用途

在 Library 中浏览已安装知识包并打开文件.

## 知识包生命周期

1. 从 Hub 安装 (远程) 或 Import (本地 `.zip`).
2. 安装后知识包会出现在 Library.
3. 应用会准备该知识包用于搜索和聊天.
4. 你可以停用、启用、升级、导出或删除知识包.

## 激活状态

- 在知识包根节点点击 `+/-` 可以切换激活状态.
- 已激活知识包会用于 Chat 回答.
- 未激活知识包仍可阅读, 但不会用于 Chat 回答.

## 导入本地知识包

zip 包应包含顶层目录 `<id>/`, 且其中必须有 `<id>/pack.json`.

`pack.json` 必填字段:

- `id`
- `name`
- `description`
- `version`

可选字段:

- `path` (如果填写, 必须与 `id` 一致)

## 删除知识包会发生什么

删除后:

- 该知识包会从本地 Library 移除
- 不再参与 Library 与 Chat 作用域
- 释放该知识包占用的本地存储空间

## 版本规则

Nest 同一知识包只保留一个已安装版本. 升级时会用新版本替换原内容.
