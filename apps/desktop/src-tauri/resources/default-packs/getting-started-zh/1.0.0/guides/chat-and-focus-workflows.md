# Chat 与 `@` 聚焦工作流

## 基础提问

不使用 `@` 时, Chat 会基于所有已激活知识包回答问题.

## 聚焦提问

在输入框输入 `@`, 选择一个或多个文件/文件夹, 让回答范围更聚焦.

### 示例问题

```text
@getting-started-zh/guides 比较从 Hub 下载和本地导入这两种工作流.
```

```text
@getting-started-zh/guides/markdown-syntax-and-highlighting.md 这个应用支持哪些 markdown 扩展?
```

## 提升回答质量的建议

1. 至少保持一个相关知识包处于激活状态.
2. 对具体问题使用更精确的 `@` 路径.
3. 问题尽量具体并带上约束条件.
4. 如果回答太泛, 检查引用来源是否匹配你的预期.

## 会话与历史

- 使用标签页管理当前进行中的对话.
- 在 History 中可 pin、archive、rename、delete 会话.
- 如果标题仍是占位文本, 首次回复后应用可能自动生成简短标题.
