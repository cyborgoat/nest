# Chat and `@` Focus Workflows

## Baseline chat

Ask a question with no `@` mentions to use all active packs.

## Focused chat

Type `@` in the composer and select one or more files/folders to narrow the answer scope.

### Example prompts

```text
@getting-started/guides Compare hub download and local import workflows.
```

```text
@getting-started/guides/markdown-syntax-and-highlighting.md What markdown extensions are supported?
```

## Best practices for higher quality answers

1. Keep at least one relevant pack active.
2. Use targeted `@` paths for specific questions.
3. Ask concrete questions with constraints.
4. Inspect citations when answers look too broad.

## Sessions and history

- Use tabs for active conversations.
- Use History to pin, archive, rename, and delete sessions.
- If title is still placeholder, app can auto-generate a short title after the first assistant reply.
