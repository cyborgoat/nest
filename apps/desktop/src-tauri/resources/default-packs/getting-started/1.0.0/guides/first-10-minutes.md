# First 10 Minutes

This walkthrough takes you from launch to useful answers.

## 1) Open Library

- Expand the preinstalled `getting-started` pack.
- Open this page and confirm markdown renders correctly.

## 2) Configure Settings

Go to Settings and provide:

- LLM Base URL
- API key
- Chat model

Optional:

- Hub Base URL (if you want remote packs)
- Your display name
- Font size
- Custom knowledge directory

## 3) Ask your first question

Open Chat and ask:

```text
Summarize how active and inactive packs affect answers in this app.
```

Then open citations to confirm which files were used.

## 4) Try focused chat

In Chat, type `@` and pick a file or folder from active packs. Example:

```text
@getting-started/guides How do I import a local pack zip?
```

## 5) Optional: connect Hub

If you run the Hub service, set Hub Base URL and open Hub:

- Browse: find and download remote packs
- Installed: upgrade/remove/manage active state

## 6) Review your setup

- Confirm at least one pack is active.
- Ask one broad question and one focused `@` question.
- Save or pin the chat session if you want to keep it easy to find later.
