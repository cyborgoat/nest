# How To Use Nest

Nest helps you read knowledge packs and ask questions over the content you choose.

## Main areas

1. Library: browse installed packs and open files.
2. Chat: ask questions and optionally focus to specific files/folders.
3. Hub: download, update, import, export, and remove packs.
4. Settings: configure your model connection and app preferences.

## Typical daily flow

1. Open Library and activate the packs you want to use.
2. Read files to understand the available content.
3. Open Chat and ask questions.
4. Use `@` mentions to focus answers when needed.
5. Manage packs in Hub as your needs change.

## Active vs inactive packs

- Active packs are used when answering questions.
- Inactive packs stay readable in Library, but are ignored by Chat.

## `@` focus

In Chat, type `@` and choose files or folders to narrow answers to a specific topic.

## Offline-friendly usage

- You can read installed packs anytime.
- You can import local `.zip` packs without connecting to Hub.
